# Draft PR: intent

Draft PR prepares concise pull request titles and descriptions for reviewers.
Its purpose is to explain the actual change, its motivation, and its validation
using repository evidence and supplied context.

The skill supports new drafts, revisions, and reviews of existing PR copy.
It also supplies the writing phase of a separately authorized publishing
workflow. Drafting copy and creating a pull request with draft status are
distinct operations.

Accuracy takes priority over making incomplete evidence look publication-ready.
The skill should identify the actual comparison, expose unrelated changes or
missing evidence, and return exact copy with a clear handoff status.

Repository repair and publication belong to separate workflows. The boundaries,
output requirements, and limitations are recorded in [spec.md](spec.md).
